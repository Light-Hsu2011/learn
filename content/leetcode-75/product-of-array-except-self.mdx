# Product of Array Except Self

<ELI5>
想像你站在一排人中間，要算出除了你以外所有人的身高乘積。如果你站在第 3 個位置，就是「你左邊所有人的身高乘積」×「你右邊所有人的身高乘積」。

做法是先從左到右算一遍「左邊累積乘積」，再從右到左算一遍「右邊累積乘積」，最後把對應位置的左右乘在一起就是答案。
</ELI5>

## 題目描述

給定整數陣列 `nums`，回傳陣列 `answer`，其中 `answer[i]` 等於 `nums` 中除了 `nums[i]` 以外所有元素的乘積。不能使用除法，且要求 O(n) 時間。

```
輸入：nums = [1,2,3,4]
輸出：[24,12,8,6]

輸入：nums = [-1,1,0,-3,3]
輸出：[0,0,9,0,0]
```

## 解題思路

<StepDiagram data='[{"title":"前綴積","description":"prefix[i] = nums[0] × nums[1] × ... × nums[i-1]","icon":"1"},{"title":"後綴積","description":"suffix[i] = nums[i+1] × nums[i+2] × ... × nums[n-1]","icon":"2"},{"title":"合併","description":"answer[i] = prefix[i] × suffix[i]","icon":"3"}]' />

## 程式碼

### C#

```csharp
public class Solution {
    public int[] ProductExceptSelf(int[] nums) {
        int n = nums.Length;
        int[] answer = new int[n];

        // 前綴積：answer[i] 先存左邊的累積乘積
        answer[0] = 1;
        for (int i = 1; i < n; i++)
            answer[i] = answer[i - 1] * nums[i - 1];

        // 後綴積：用一個變數從右邊累積，乘進 answer
        int suffix = 1;
        for (int i = n - 2; i >= 0; i--) {
            suffix *= nums[i + 1];
            answer[i] *= suffix;
        }
        return answer;
    }
}
```

### Python

```python
def productExceptSelf(nums: list[int]) -> list[int]:
    n = len(nums)
    answer = [1] * n

    # 前綴積
    for i in range(1, n):
        answer[i] = answer[i - 1] * nums[i - 1]

    # 後綴積
    suffix = 1
    for i in range(n - 2, -1, -1):
        suffix *= nums[i + 1]
        answer[i] *= suffix

    return answer
```

## 進階觀點

<Callout type="tip" title="面試追問">
- **為什麼不能用除法？** 陣列可能含有 0，除以 0 會出問題。題目也明確禁止。
- **如果允許除法？** 先算全部乘積，再除以各自值。但要處理 0 的特殊情況（0 個零、1 個零、多個零）。
- **這個前綴/後綴技巧還能用在哪？** Trapping Rain Water、Minimum Cost to Make Array Equal 等題。
</Callout>
