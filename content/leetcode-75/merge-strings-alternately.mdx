# Merge Strings Alternately

<ELI5>
想像你跟朋友在打牌，你們各有一疊牌。你先出一張，朋友出一張，你再出一張⋯⋯交替出牌直到某人手上沒牌了，剩下的人就把手上的牌全部放上去。

這題就是這樣 — 兩個字串就像兩疊牌，我們交替從中取出字元，拼成一個新字串。誰先用完，剩下的那個就把尾巴全部接上去。
</ELI5>

## 題目描述

給定兩個字串 `word1` 和 `word2`，交替合併它們的字元。如果某個字串比較長，把剩餘的字元接在合併結果的後面。

```
輸入：word1 = "abc", word2 = "pqr"
輸出："apbqcr"

輸入：word1 = "ab", word2 = "pqrs"
輸出："apbqrs"
```

## 程式碼

### C#

```csharp
public class Solution {
    public string MergeAlternately(string word1, string word2) {
        var sb = new System.Text.StringBuilder();
        int i = 0;
        // 交替取字元
        while (i < word1.Length || i < word2.Length) {
            if (i < word1.Length) sb.Append(word1[i]);
            if (i < word2.Length) sb.Append(word2[i]);
            i++;
        }
        return sb.ToString();
    }
}
```

### TypeScript

```typescript
function mergeAlternately(word1: string, word2: string): string {
    let result = "";
    let i = 0;
    // 交替取字元，超出長度的自動跳過
    while (i < word1.length || i < word2.length) {
        if (i < word1.length) result += word1[i];
        if (i < word2.length) result += word2[i];
        i++;
    }
    return result;
}
```

### Python

```python
def mergeAlternately(word1: str, word2: str) -> str:
    result = []
    i = 0
    # 交替取字元
    while i < len(word1) or i < len(word2):
        if i < len(word1):
            result.append(word1[i])
        if i < len(word2):
            result.append(word2[i])
        i += 1
    return "".join(result)
```

## 複雜度分析

| | Time | Space |
|--|------|-------|
| 本解法 | O(n + m) | O(n + m) |

其中 n、m 分別為兩字串長度。

## 進階觀點

<Callout type="tip" title="面試追問">
- **如果有三個以上字串要交替合併？** 改用 index 搭配 for 迴圈遍歷所有字串。
- **能否 in-place？** 字串在大多數語言是 immutable，所以需要額外空間。
- **跟 zip_longest 的關係？** Python 可直接用 `itertools.zip_longest` 一行解決。
</Callout>
