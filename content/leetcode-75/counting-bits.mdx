# Counting Bits

<ELI5>
把 0 到 n 的每個數字用二進位寫出來，數一數每個數字有幾個「1」。

例如：0→0, 1→1, 2→10, 3→11, 4→100, 5→101

有個巧妙的規律：任何數字 i 的 1 的個數 = i 右移一位的 1 的個數 + i 的最後一位是不是 1。

例如 5 (101)：5 >> 1 = 2 (10)，2 有 1 個 1，5 的最後一位是 1，所以 5 有 1+1 = 2 個 1。

就像查字典：你要知道 "unhappy" 的意思，先查 "happy"（已經查過了），再加上 "un-" 的影響。
</ELI5>

## 題目描述

給定整數 n，回傳陣列 ans，其中 ans[i] 是 i 的二進位表示中 1 的個數（`0 ≤ i ≤ n`）。

```
輸入：n = 5
輸出：[0,1,1,2,1,2]

輸入：n = 2
輸出：[0,1,1]
```

## 解題思路

<StepDiagram data='[{"title":"觀察規律","description":"i 的 1 的個數 = (i >> 1) 的 1 的個數 + (i & 1)","icon":"1"},{"title":"DP 遞推","description":"dp[i] = dp[i >> 1] + (i & 1)","icon":"2"},{"title":"從小到大","description":"從 0 開始算，每個數字的結果依賴更小的數字","icon":"3"},{"title":"一次遍歷","description":"O(n) 時間完成所有計算","icon":"4"}]' />

## 程式碼

### C#
```csharp
public class Solution {
    public int[] CountBits(int n) {
        int[] dp = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            // i >> 1 去掉最後一位，i & 1 取最後一位
            dp[i] = dp[i >> 1] + (i & 1);
        }
        return dp;
    }
}
```

### TypeScript
```typescript
function countBits(n: number): number[] {
    const dp = new Array(n + 1).fill(0);
    for (let i = 1; i <= n; i++) {
        dp[i] = dp[i >> 1] + (i & 1);
    }
    return dp;
}
```

### Python
```python
def countBits(n: int) -> list[int]:
    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        dp[i] = dp[i >> 1] + (i & 1)
    return dp
```

## 進階觀點

<Callout type="tip" title="面試追問">
- 另一個遞推關係：`dp[i] = dp[i & (i-1)] + 1`，其中 `i & (i-1)` 會去掉 i 最低位的 1。
- 不用 DP 的方法：`__builtin_popcount`（C++）、`Integer.bitCount`（Java）、`bin(i).count('1')`（Python），但時間複雜度每個數字是 O(log n)。
- Brian Kernighan 演算法：`while (n) { n &= n-1; count++; }` 可以在 O(k) 時間內數出 k 個 1，k 是 1 的個數。
</Callout>
