# String Compression

<ELI5>
想像你在整理一排重複的積木：紅紅紅藍藍綠。與其說「紅紅紅藍藍綠」，你可以簡寫成「紅3藍2綠」— 每種顏色後面加上出現次數（只有 1 個就不寫數字）。

這題要你在原地（不用額外陣列）做這件事。用一個「讀取指針」數連續相同字元，用一個「寫入指針」把壓縮結果寫回原陣列。
</ELI5>

## 題目描述

給定字元陣列 `chars`，原地壓縮。連續相同字元替換為「字元+計數」（計數為 1 時省略）。回傳壓縮後陣列的長度。

```
輸入：chars = ["a","a","b","b","c","c","c"]
輸出：6（陣列變為 ["a","2","b","2","c","3"]）

輸入：chars = ["a"]
輸出：1

輸入：chars = ["a","b","b","b","b","b","b","b","b","b","b","b","b"]
輸出：4（陣列變為 ["a","b","1","2"]）
```

## 解題思路

## 程式碼

### C#

```csharp
public class Solution {
    public int Compress(char[] chars) {
        int write = 0, read = 0;
        while (read < chars.Length) {
            char current = chars[read];
            int count = 0;
            // 計算連續相同字元數
            while (read < chars.Length && chars[read] == current) {
                read++;
                count++;
            }
            // 寫入字元
            chars[write++] = current;
            // 寫入計數（大於 1 時）
            if (count > 1) {
                foreach (char c in count.ToString())
                    chars[write++] = c;
            }
        }
        return write;
    }
}
```

### Python

```python
def compress(chars: list[str]) -> int:
    write = read = 0
    while read < len(chars):
        current = chars[read]
        count = 0
        while read < len(chars) and chars[read] == current:
            read += 1
            count += 1
        chars[write] = current
        write += 1
        if count > 1:
            for c in str(count):
                chars[write] = c
                write += 1
    return write
```

## 進階觀點

<Callout type="tip" title="面試追問">
- **計數超過 9 怎麼處理？** 如 12 要寫成 '1','2' 兩個字元，所以要把數字轉字串再逐字元寫入。
- **為什麼寫入指針不會超過讀取指針？** 因為壓縮後的長度永遠 ≤ 原始長度（最差情況相等）。
- **Run-Length Encoding 的應用？** 影像壓縮、簡單文字壓縮、面試高頻考點。
</Callout>
