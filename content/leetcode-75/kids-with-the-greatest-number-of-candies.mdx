# Kids With the Greatest Number of Candies

<ELI5>
班上每個小朋友都有一些糖果。老師手上有一些額外的糖果，想知道：如果把所有額外糖果都給某個小朋友，他的糖果數能不能成為全班最多（或並列最多）？

做法很簡單 — 先看全班誰最多糖果，然後問每個小朋友：「你現在的糖果 + 額外糖果 ≥ 目前最多的嗎？」能的話就是 true。
</ELI5>

## 題目描述

給定陣列 `candies` 和整數 `extraCandies`，回傳布林陣列，表示每個孩子加上 `extraCandies` 後是否能擁有最多糖果。

```
輸入：candies = [2,3,5,1,3], extraCandies = 3
輸出：[true,true,true,false,true]

輸入：candies = [4,2,1,1,2], extraCandies = 1
輸出：[true,false,false,false,false]
```

## 解題思路

<StepDiagram data='[{"title":"找最大值","description":"掃一遍找出 candies 中的最大值 maxCandy","icon":"1"},{"title":"逐一比較","description":"對每個 candies[i]，判斷 candies[i] + extraCandies >= maxCandy","icon":"2"},{"title":"回傳結果","description":"收集所有布林值為結果陣列","icon":"3"}]' />

## 程式碼

### C#

```csharp
public class Solution {
    public IList<bool> KidsWithCandies(int[] candies, int extraCandies) {
        int maxCandy = candies.Max();
        return candies.Select(c => c + extraCandies >= maxCandy).ToList();
    }
}
```

### TypeScript

```typescript
function kidsWithCandies(candies: number[], extraCandies: number): boolean[] {
    const maxCandy = Math.max(...candies);
    return candies.map(c => c + extraCandies >= maxCandy);
}
```

### Python

```python
def kidsWithCandies(candies: list[int], extraCandies: int) -> list[bool]:
    max_candy = max(candies)
    return [c + extraCandies >= max_candy for c in candies]
```

## 複雜度分析

| | Time | Space |
|--|------|-------|
| 本解法 | O(n) | O(n) |

找最大值 O(n) + 比較 O(n) = O(n)。輸出陣列 O(n)。

## 進階觀點

<Callout type="tip" title="面試追問">
- **如果 extraCandies 可以分給不同孩子？** 那就變成分配問題，複雜度大幅提升。
- **能否一次遍歷完成？** 可以，但需要先知道最大值，所以至少需要兩次遍歷（或先排序）。
- **這題的本質？** 就是一個 threshold 判斷，核心在於認識到只需跟最大值比較。
</Callout>
