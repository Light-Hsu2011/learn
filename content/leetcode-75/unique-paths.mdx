# Unique Paths

<ELI5>
想像你站在一個棋盤的左上角，你的目標是走到右下角。你只能往右走或往下走（不能回頭或往左）。

有幾條不同的路可以走？

這就像在城市裡從 A 走到 B，只能往東或往南——每個路口你都有兩個選擇。到達任何一個路口的方法數 = 從上面來的方法數 + 從左邊來的方法數（因為你只能從這兩個方向到達這裡）。
</ELI5>

## 題目描述

一個 m × n 的網格，機器人在左上角 (0,0)，目標在右下角 (m-1, n-1)。每次只能往下或往右走。回傳不同路徑的數量。

```
輸入：m = 3, n = 7
輸出：28

輸入：m = 3, n = 2
輸出：3
```

## 解題思路

<StepDiagram data='[{"title":"定義狀態","description":"dp[i][j] = 到達 (i,j) 的路徑數","icon":"1"},{"title":"邊界條件","description":"第一行和第一列都只有 1 種走法","icon":"2"},{"title":"轉移方程","description":"dp[i][j] = dp[i-1][j] + dp[i][j-1]","icon":"3"},{"title":"空間優化","description":"逐行計算，只需要一維陣列","icon":"4"},{"title":"回傳結果","description":"dp[m-1][n-1] 即答案","icon":"5"}]' />

## 程式碼

### C#
```csharp
public class Solution {
    public int UniquePaths(int m, int n) {
        // 空間優化：用一維陣列
        int[] dp = new int[n];
        Array.Fill(dp, 1); // 第一行全是 1
        
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[j] += dp[j - 1]; // dp[j] 本身是上方的值，dp[j-1] 是左邊的值
            }
        }
        return dp[n - 1];
    }
}
```

### TypeScript
```typescript
function uniquePaths(m: number, n: number): number {
    const dp = new Array(n).fill(1);
    
    for (let i = 1; i < m; i++) {
        for (let j = 1; j < n; j++) {

    }

}
```

### Python
```python
def uniquePaths(m: int, n: int) -> int:
    dp = [1] * n  # 第一行都是 1
    
    for i in range(1, m):
        for j in range(1, n):
            dp[j] += dp[j - 1]  # 上方 + 左方
    
    return dp[n - 1]
```

## 進階觀點

<Callout type="tip" title="面試追問">
- 數學解法：從左上到右下總共走 (m-1)+(n-1) 步，其中 m-1 步向下，n-1 步向右，答案是 C(m+n-2, m-1) 組合數。
- **63. Unique Paths II** 加入了障礙物，只需在障礙格子設 dp=0 即可。
- **64. Minimum Path Sum** 是本題的帶權版本，求最小路徑和。
- 空間優化的關鍵觀察：計算第 i 行時，dp[j] 還存著第 i-1 行的值（上方），dp[j-1] 已更新為第 i 行的值（左方）。
</Callout>
