# Delete the Middle Node of a Linked List

<ELI5>
想像一排小朋友手牽手排隊。你想找出正中間那個人，但你不知道隊伍有多長。

有個聰明的方法：派兩個人從隊伍頭出發。一個人每次走一步（慢指針），另一個每次走兩步（快指針）。當走得快的到隊尾時，走得慢的剛好在中間！

然後你只要把中間那個人的左右鄰居牽在一起，中間人就被「跳過」了。
</ELI5>

## 題目描述

給定一個 Linked List 的 head，刪除中間節點並回傳修改後的 head。中間節點定義為第 ⌊n/2⌋ 個節點（0-indexed）。

```
輸入: [1,3,4,7,1,2,6]
輸出: [1,3,4,1,2,6]
解釋: 中間節點是 index 3 的 7

輸入: [1,2,3,4]
輸出: [1,2,4]
解釋: 中間節點是 index 2 的 3
```

## 程式碼

### C#

```csharp
public class Solution {
    public ListNode DeleteMiddle(ListNode head) {
        if (head.next == null) return null; // 只有一個節點

        // slow 從 dummy 開始，這樣停下時 slow.next 就是中點
        var dummy = new ListNode(0, head);
        var slow = dummy;
        var fast = head;

        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        slow.next = slow.next.next; // 跳過中間節點
        return dummy.next;
    }
}
```

### TypeScript

```typescript
function deleteMiddle(head: ListNode | null): ListNode | null {
    if (!head || !head.next) return null; // 空或只有一個節點

    const dummy = new ListNode(0, head);
    let slow: ListNode = dummy;
    let fast: ListNode | null = head;

    while (fast && fast.next) {
        slow = slow.next!;
        fast = fast.next.next;
    }

    slow.next = slow.next!.next; // 跳過中間節點
    return dummy.next;
}
```

### Python

```python
def deleteMiddle(head: Optional[ListNode]) -> Optional[ListNode]:
    if not head.next:
        return None  # 只有一個節點

    dummy = ListNode(0, head)
    slow = dummy
    fast = head

    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next

    slow.next = slow.next.next  # 跳過中間節點
    return dummy.next
```

## 進階觀點

<Callout type="tip" title="面試追問">
**為什麼 slow 從 dummy 開始？** 因為我們需要停在中間節點的「前一個」，才能執行刪除。如果 slow 從 head 開始，停下時就已經是中間節點本身了。

**變體題**：LC 876 Middle of the Linked List（找中點不刪除）、LC 19 Remove Nth Node From End（刪倒數第 n 個）。
</Callout>
