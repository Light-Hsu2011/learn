# Removing Stars From a String

<ELI5>
想像你在打字，每打一個 `*` 就等於按了一次退格鍵（Backspace），會刪掉前面一個字。

比如你打了 "leet**cod*e"：l-e-e-t-退格-退格-c-o-d-退格-e = "lecoe"。

用 Stack 來模擬：普通字元就推入，遇到 `*` 就彈出最上面的。最後 Stack 裡剩下的就是答案。
</ELI5>

## 題目描述

給定包含星號 `*` 的字串 `s`。每次操作移除最靠近星號左邊的非星號字元，以及星號本身。回傳移除所有星號後的結果。

```
輸入：s = "leet**cod*e"
輸出："lecoe"

輸入：s = "erase*****"
輸出：""
```

## 程式碼

### C#

```csharp
public class Solution {
    public string RemoveStars(string s) {
        var stack = new Stack<char>();
        foreach (char c in s) {
            if (c == '*')
                stack.Pop();   // 刪除前一個字元
            else
                stack.Push(c); // 保留字元
        }
        // Stack 是後進先出，需要反轉
        var arr = stack.ToArray();
        Array.Reverse(arr);
        return new string(arr);
    }
}
```

### TypeScript

```typescript
function removeStars(s: string): string {
    const stack: string[] = [];
    for (const c of s) {
        if (c === "*") stack.pop();
        else stack.push(c);
    }
    return stack.join("");
}
```

### Python

```python
def removeStars(s: str) -> str:
    stack = []
    for c in s:
        if c == "*":
            stack.pop()
        else:
            stack.append(c)
    return "".join(stack)
```

## 複雜度分析

| | Time | Space |
|--|------|-------|
| 本解法 | O(n) | O(n) |

每個字元最多被 push 和 pop 各一次。

## 進階觀點

<Callout type="tip" title="面試追問">
- **能否不用 Stack？** 可以用一個 write 指針在原陣列上操作（類似 String Compression），遇到 `*` 就 write--。
- **C# 為什麼要 Reverse？** C# 的 `Stack<T>.ToArray()` 是從頂端開始輸出（後進先出），需要反轉。用 `StringBuilder` 或 `List<char>` 可以避免。
- **如果星號可以刪除多個字元呢？** 那需要數字+星號的格式，解法會更複雜。
</Callout>
