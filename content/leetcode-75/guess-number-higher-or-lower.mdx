# Guess Number Higher or Lower

<ELI5>
這就是小時候玩的猜數字遊戲！我心裡想一個 1 到 N 的數字，你每次猜一個，我告訴你「太高了」、「太低了」或「猜對了」。

最聰明的策略是什麼？每次都猜中間的數字！這樣不管答案在左邊還是右邊，你都能一次淘汰一半的可能性。猜 1~100 的數字，最多只要猜 7 次（因為 2^7 = 128 > 100）。
</ELI5>

## 題目描述

猜一個 1 到 n 的數字，有一個預定義的 API `guess(num)` 回傳 `-1`（太高）、`1`（太低）或 `0`（正確）。找出正確的數字。

```
輸入：n = 10, pick = 6
輸出：6
解釋：guess(5) → 1, guess(8) → -1, guess(7) → -1, guess(6) → 0
```

## 解題思路

## 程式碼

### C#
```csharp
public class Solution : GuessGame {
    public int GuessNumber(int n) {
        int left = 1, right = n;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            int result = guess(mid);
            if (result == 0) return mid;
            else if (result == -1) right = mid - 1; // 太高
            else left = mid + 1; // 太低
        }
        return -1; // 不會到這裡
    }
}
```

### TypeScript
```typescript
function guessNumber(n: number): number {
    let left = 1, right = n;
    while (left <= right) {
        const mid = Math.floor(left + (right - left) / 2);
        const result = guess(mid);
        if (result === 0) return mid;
        else if (result === -1) right = mid - 1;
        else left = mid + 1;
    }
    return -1;
}
```

### Python
```python
def guessNumber(n: int) -> int:
    left, right = 1, n
    while left <= right:
        mid = left + (right - left) // 2
        result = guess(mid)
        if result == 0:
            return mid
        elif result == -1:  # 猜太高
            right = mid - 1
        else:  # 猜太低
            left = mid + 1
    return -1
```

## 進階觀點

<Callout type="tip" title="面試追問">
- 為什麼用 `left + (right - left) / 2` 而不是 `(left + right) / 2`？防止整數溢位，特別是在 C# / Java 中 int 的上限約 21 億。
- Binary Search 的三種常見變體：找精確值、找左邊界、找右邊界，模板略有不同。
- 這是 **Interactive Binary Search** 的範例，面試中常見的延伸是猜測有誤差（如 2-3 次錯誤回饋），需要三分搜尋或多次確認。
</Callout>
