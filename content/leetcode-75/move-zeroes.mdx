# Move Zeroes

<ELI5>
想像一排座位上坐了一些人（非零）和一些空位（零）。你要把所有人往前移動，保持他們原本的順序，空位全部推到最後。

做法是用一個「安排座位」的指針（slow），從左到右掃描每個位置（fast）。每次看到有人坐著，就把他搬到 slow 指向的位置，然後 slow 前進一格。掃完之後 slow 後面的位置全填零。
</ELI5>

## 題目描述

給定整數陣列 `nums`，將所有 0 移動到陣列末尾，同時保持非零元素的相對順序。必須原地操作。

```
輸入：nums = [0,1,0,3,12]
輸出：[1,3,12,0,0]

輸入：nums = [0]
輸出：[0]
```

## 解題思路

## 程式碼

### C#

```csharp
public class Solution {
    public void MoveZeroes(int[] nums) {
        int slow = 0;
        for (int fast = 0; fast < nums.Length; fast++) {
            if (nums[fast] != 0) {
                // 交換：非零元素往前搬
                (nums[slow], nums[fast]) = (nums[fast], nums[slow]);
                slow++;
            }
        }
    }
}
```

### TypeScript

```typescript
function moveZeroes(nums: number[]): void {
    let slow = 0;
    for (let fast = 0; fast < nums.length; fast++) {
        if (nums[fast] !== 0) {
            [nums[slow], nums[fast]] = [nums[fast], nums[slow]];
            slow++;
        }
    }
}
```

### Python

```python
def moveZeroes(nums: list[int]) -> None:
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow], nums[fast] = nums[fast], nums[slow]
            slow += 1
```

## 進階觀點

<Callout type="tip" title="面試追問">
- **為什麼用交換而不是直接覆蓋再補零？** 兩種都可以。交換的好處是一次遍歷搞定，不需要第二次遍歷補零。
- **如果要保持零的位置不變，移動非零元素？** 題意不同，需要不同策略。
- **快慢指針模式還能用在哪？** 移除特定元素、去除重複元素、鏈表找環等。
</Callout>
