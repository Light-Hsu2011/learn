# Longest Common Subsequence

<ELI5>
想像兩個朋友各自按順序講了一串故事關鍵字。你想找出他們兩個人都提到的關鍵字，而且出現的順序要一致（但不需要連續）。

例如 "abcde" 和 "ace"，兩個人都按順序提到了 a、c、e，這就是最長的「公共子序列」，長度是 3。

解法像填一張表格：橫軸是第一個人的故事，縱軸是第二個人的故事。每格問「到這裡為止，他們共同提到了幾個字？」如果當前的字一樣，就在左上角的值加 1；不一樣，就取左邊或上面的較大值。
</ELI5>

## 題目描述

給定兩個字串 `text1` 和 `text2`，回傳它們的最長公共子序列（LCS）的長度。子序列不需要連續，但順序要保持。

```
輸入：text1 = "abcde", text2 = "ace"
輸出：3
解釋：LCS 是 "ace"

輸入：text1 = "abc", text2 = "def"
輸出：0
```

## 解題思路

<StepDiagram data='[{"title":"定義狀態","description":"dp[i][j] = text1[0..i-1] 和 text2[0..j-1] 的 LCS 長度","icon":"1"},{"title":"字元相同","description":"dp[i][j] = dp[i-1][j-1] + 1","icon":"2"},{"title":"字元不同","description":"dp[i][j] = max(dp[i-1][j], dp[i][j-1])","icon":"3"},{"title":"填表方向","description":"從左上到右下逐格填表","icon":"4"},{"title":"答案","description":"dp[m][n] 即為 LCS 長度","icon":"5"}]' />

## 程式碼

### C#
```csharp
public class Solution {
    public int LongestCommonSubsequence(string text1, string text2) {
        int m = text1.Length, n = text2.Length;
        // 空間優化：只用一維陣列
        int[] dp = new int[n + 1];
        
        for (int i = 1; i <= m; i++) {
            int prev = 0; // dp[i-1][j-1]
            for (int j = 1; j <= n; j++) {
                int temp = dp[j]; // 暫存 dp[i-1][j]
                if (text1[i - 1] == text2[j - 1]) {
                    dp[j] = prev + 1;
                } else {
                    dp[j] = Math.Max(dp[j], dp[j - 1]);
                }
                prev = temp;
            }
        }
        return dp[n];
    }
}
```

### TypeScript
```typescript
function longestCommonSubsequence(text1: string, text2: string): number {
    const m = text1.length, n = text2.length;
    const dp: number[][] = Array.from({length: m + 1}, () => new Array(n + 1).fill(0));
    
    for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {
            if (text1[i - 1] === text2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}
```

### Python
```python
def longestCommonSubsequence(text1: str, text2: str) -> int:
    m, n = len(text1), len(text2)
    # 空間優化版本
    dp = [0] * (n + 1)
    
    for i in range(1, m + 1):
        prev = 0
        for j in range(1, n + 1):
            temp = dp[j]
            if text1[i - 1] == text2[j - 1]:
                dp[j] = prev + 1
            else:
                dp[j] = max(dp[j], dp[j - 1])
            prev = temp
    
    return dp[n]
```

## 進階觀點

<Callout type="tip" title="面試追問">
- 如果要輸出實際的 LCS 字串（不只是長度），需要從 dp 表格反向追溯路徑。
- **583. Delete Operation for Two Strings**：刪除操作數 = m + n - 2 × LCS。
- **72. Edit Distance** 是 LCS 的延伸，增加了「替換」操作。
- LCS 在 diff 工具、版本控制、DNA 序列比對中都有實際應用。
</Callout>
