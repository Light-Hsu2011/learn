# Domino and Tromino Tiling

<ELI5>
想像你有一個 2 行 N 列的長條地板，你要用兩種磁磚鋪滿它：
- Domino（骨牌）：2×1 的長方形，可以橫放或直放
- Tromino（L 形磁磚）：佔 3 格的 L 形，可以旋轉成 4 個方向

問題是：有幾種不同的鋪法？

這就像拼拼圖：每次你放一塊磁磚，地板的「剩餘形狀」會改變。我們用狀態來記錄每一列的填充情況，然後推導出從一個狀態到下一個狀態的轉移關係。
</ELI5>

## 題目描述

用 Domino（2×1）和 Tromino（L 形）鋪滿 2×n 的棋盤，回傳方法數（mod 10^9+7）。

```
輸入：n = 3
輸出：5

輸入：n = 1
輸出：1
```

## 程式碼

### C#
```csharp
public class Solution {
    public int NumTilings(int n) {
        const int MOD = 1_000_000_007;
        if (n <= 2) return n;
        
        long[] dp = new long[n + 1];
        dp[0] = 1; dp[1] = 1; dp[2] = 2;
        
        for (int i = 3; i <= n; i++) {
            // f(n) = 2*f(n-1) + f(n-3)
            dp[i] = (2 * dp[i - 1] + dp[i - 3]) % MOD;
        }
        return (int)dp[n];
    }
}
```

### Python
```python
def numTilings(n: int) -> int:
    MOD = 10**9 + 7
    if n <= 2:
        return n
    
    dp = [0] * (n + 1)
    dp[0], dp[1], dp[2] = 1, 1, 2
    
    for i in range(3, n + 1):
        dp[i] = (2 * dp[i - 1] + dp[i - 3]) % MOD
    
    return dp[n]
```

## 進階觀點

<Callout type="tip" title="面試追問">
- 遞推式 `f(n) = 2*f(n-1) + f(n-3)` 怎麼推導？考慮最後一列的填充方式：可以放一個直立 Domino（對應 f(n-1)），放兩個橫放 Domino（對應 f(n-2)），或放 Tromino 加 Domino 組合（引入 f(n-3) 項）。
- 也可以用「完整狀態」和「部分突出狀態」兩個 DP 陣列來推導，更直觀但稍微複雜。
- n 非常大時可以用矩陣快速冪優化到 O(log n)。
</Callout>
