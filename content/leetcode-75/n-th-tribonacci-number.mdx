# N-th Tribonacci Number

<ELI5>
你知道 Fibonacci 數列嗎？每一項是前兩項的和（0, 1, 1, 2, 3, 5...）。Tribonacci 就是它的升級版——每一項是前**三**項的和！

T(0) = 0, T(1) = 1, T(2) = 1
T(3) = 0+1+1 = 2
T(4) = 1+1+2 = 4
T(5) = 1+2+4 = 7

就像接力賽：每個選手的速度等於前面三個選手速度的總和。你只需要記住最近三個選手的速度就夠了，不用記住所有人。
</ELI5>

## 題目描述

Tribonacci 數列定義：T(0)=0, T(1)=1, T(2)=1，T(n) = T(n-1) + T(n-2) + T(n-3)（`n ≥ 3`）。給定 n，回傳 T(n)。

```
輸入：n = 4
輸出：4
解釋：T(4) = T(3) + T(2) + T(1) = 2 + 1 + 1 = 4

輸入：n = 25
輸出：1389537
```

## 程式碼

### C#
```csharp
public class Solution {
    public int Tribonacci(int n) {
        if (n == 0) return 0;
        if (n <= 2) return 1;
        
        int t0 = 0, t1 = 1, t2 = 1;
        for (int i = 3; i <= n; i++) {
            int next = t0 + t1 + t2;
            t0 = t1;
            t1 = t2;
            t2 = next;
        }
        return t2;
    }
}
```

### TypeScript
```typescript
function tribonacci(n: number): number {
    if (n === 0) return 0;
    if (n <= 2) return 1;
    
    let [t0, t1, t2] = [0, 1, 1];
    for (let i = 3; i <= n; i++) {
        const next = t0 + t1 + t2;
        [t0, t1, t2] = [t1, t2, next];
    }
    return t2;
}
```

### Python
```python
def tribonacci(n: int) -> int:
    if n == 0:
        return 0
    if n <= 2:
        return 1
    
    t0, t1, t2 = 0, 1, 1
    for _ in range(3, n + 1):
        t0, t1, t2 = t1, t2, t0 + t1 + t2
    return t2
```

## 進階觀點

<Callout type="tip" title="面試追問">
- 滾動變數是 DP 空間優化的經典技巧：原本需要 O(n) 的陣列，只用三個變數就能解決。
- 如果 n 非常大（如 10^18），可以用矩陣快速冪將時間降到 O(log n)。
- Fibonacci / Tribonacci 是理解 DP 的最佳入門題，核心概念：「當前狀態只依賴有限的前幾個狀態」。
</Callout>
