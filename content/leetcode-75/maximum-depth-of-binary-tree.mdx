# Maximum Depth of Binary Tree

<ELI5>
想像一棵家族樹。你想知道「這個家族最多傳了幾代？」

你可以問每個人：「你的子孫最多傳了幾代？」每個人問自己的左邊小孩和右邊小孩，取比較多的那個再加 1（加上自己這一代）。如果沒有小孩，答案就是 0。

這就是遞迴的精髓 — 把大問題拆成小問題，從葉子往上匯總。
</ELI5>

## 題目描述

給定一棵二元樹的根節點 root，回傳其最大深度。最大深度是從根到最遠葉節點的最長路徑上的節點數。

```
輸入:     3
         / \
        9  20
           / \
          15   7
輸出: 3

輸入:   1
         \
          2
輸出: 2
```

## 解題思路

<StepDiagram data='[{"title":"Base Case","description":"節點為 null 時回傳 0","icon":"1"},{"title":"遞迴左子樹","description":"取得左子樹的最大深度","icon":"2"},{"title":"遞迴右子樹","description":"取得右子樹的最大深度","icon":"3"},{"title":"合併結果","description":"回傳 max(左, 右) + 1","icon":"4"}]' />

## 程式碼

### C#

```csharp
public class Solution {
    public int MaxDepth(TreeNode root) {
        if (root == null) return 0;
        int left = MaxDepth(root.left);
        int right = MaxDepth(root.right);
        return Math.Max(left, right) + 1;
    }
}
```

### TypeScript

```typescript
function maxDepth(root: TreeNode | null): number {
    if (!root) return 0;
    const left = maxDepth(root.left);
    const right = maxDepth(root.right);
    return Math.max(left, right) + 1;
}
```

### Python

```python
def maxDepth(root: Optional[TreeNode]) -> int:
    if not root:
        return 0
    left = maxDepth(root.left)
    right = maxDepth(root.right)
    return max(left, right) + 1
```

## 複雜度分析

| | Time | Space |
|--|------|-------|
| 本解法 | O(n) | O(h) |

n 是節點數，h 是樹高（遞迴 call stack）。最壞情況（skewed tree）h = n。

## 進階觀點

<Callout type="tip" title="面試追問">
**BFS 解法**：也可以用 BFS 逐層遍歷，層數就是深度。面試可能要求寫 iterative 版本。

**DFS vs BFS 選擇**：求深度用 DFS 更自然（遞迴一行搞定），求層級相關資訊（如每層最大值）用 BFS 更直覺。

**變體題**：LC 111 Minimum Depth（最小深度，注意邊界）、LC 110 Balanced Binary Tree（深度差不超過 1）。
</Callout>
