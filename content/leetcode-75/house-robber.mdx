# House Robber

<ELI5>
你是一個小偷，沿著一條街偷東西。每棟房子裡有不同金額的財寶，但有一個限制：不能偷相鄰的兩棟房子（因為會觸發警報）。

你站在每棟房子前面要做一個決定：偷還是不偷？
- 偷的話：拿到這棟的錢，但前一棟不能偷（所以加上「前前棟為止的最大收益」）
- 不偷的話：你的收益跟站在前一棟時一樣

每棟房子都做最聰明的選擇，最後的總收益就是最大值。
</ELI5>

## 題目描述

給定一個非負整數陣列 `nums`，代表每棟房子的金額。不能偷相鄰兩棟，回傳能偷到的最大金額。

```
輸入：nums = [1,2,3,1]
輸出：4
解釋：偷第 0 棟(1) + 第 2 棟(3) = 4

輸入：nums = [2,7,9,3,1]
輸出：12
解釋：偷第 0 棟(2) + 第 2 棟(9) + 第 4 棟(1) = 12
```

## 解題思路

<StepDiagram data='[{"title":"定義狀態","description":"dp[i] = 考慮前 i 棟房子能偷到的最大金額","icon":"1"},{"title":"轉移方程","description":"dp[i] = max(dp[i-1], dp[i-2] + nums[i])","icon":"2"},{"title":"偷 or 不偷","description":"不偷第 i 棟 → dp[i-1]；偷第 i 棟 → dp[i-2] + nums[i]","icon":"3"},{"title":"空間優化","description":"只需前兩個值，用兩個變數滾動","icon":"4"}]' />

## 程式碼

### C#
```csharp
public class Solution {
    public int Rob(int[] nums) {
        if (nums.Length == 1) return nums[0];
        
        int prev2 = 0; // dp[i-2]
        int prev1 = 0; // dp[i-1]
        
        foreach (int num in nums) {
            int curr = Math.Max(prev1, prev2 + num);
            prev2 = prev1;
            prev1 = curr;
        }
        return prev1;
    }
}
```

### TypeScript
```typescript
function rob(nums: number[]): number {
    let prev2 = 0; // 前前棟的最大收益
    let prev1 = 0; // 前一棟的最大收益
    
    for (const num of nums) {
        const curr = Math.max(prev1, prev2 + num);
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}
```

### Python
```python
def rob(nums: list[int]) -> int:
    prev2, prev1 = 0, 0  # dp[i-2], dp[i-1]
    
    for num in nums:
        curr = max(prev1, prev2 + num)
        prev2, prev1 = prev1, curr
    
    return prev1
```

## 進階觀點

<Callout type="tip" title="面試追問">
- **213. House Robber II**：房子排成環形，第一棟和最後一棟也相鄰。解法：跑兩次，分別排除第一棟和最後一棟，取較大值。
- **337. House Robber III**：房子排成樹形結構，需要樹形 DP。
- 本題的轉移方程 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` 是「取或不取」決策的經典範本，適用於所有「不相鄰選擇」的問題。
</Callout>
