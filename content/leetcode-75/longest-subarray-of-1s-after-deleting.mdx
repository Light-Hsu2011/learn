# Longest Subarray of 1's After Deleting One Element

<ELI5>
跟上一題（Max Consecutive Ones III）幾乎一樣！差別在於：你不是「把 0 變成 1」，而是「刪掉一個元素」。因為必須刪除恰好一個元素，所以最終答案要減 1。

就像一串珍珠項鍊，允許拿掉一顆黑珠子，看最長能串多少白珠子。但因為拿掉後少了一個位置，長度自然少 1。
</ELI5>

## 題目描述

給定二進位陣列 `nums`，刪除恰好一個元素後，回傳最長的全 1 子陣列長度。

```
輸入：nums = [1,1,0,1,1,1,0,1,1]
輸出：5（刪除 nums[2]，得到 [1,1,1,1,1]）

輸入：nums = [0,1,1,1,0,1,1,0,1]
輸出：4

輸入：nums = [1,1,1]
輸出：2（必須刪除一個元素）
```

## 解題思路

<StepDiagram data='[{"title":"等同上題","description":"滑動窗口允許最多 1 個 0（k=1）","icon":"1"},{"title":"擴張右邊","description":"right 往右移，追蹤 0 的數量","icon":"2"},{"title":"收縮左邊","description":"0 的數量超過 1 時，left 收縮","icon":"3"},{"title":"結果減一","description":"窗口長度 - 1 就是刪除一個元素後的長度","icon":"4"}]' />

## 程式碼

### C#

```csharp
public class Solution {
    public int LongestSubarray(int[] nums) {
        int left = 0, zeroCount = 0, maxLen = 0;
        for (int right = 0; right < nums.Length; right++) {
            if (nums[right] == 0) zeroCount++;
            while (zeroCount > 1) {
                if (nums[left] == 0) zeroCount--;
                left++;
            }
            // 窗口長度 - 1（因為必須刪除一個元素）
            maxLen = Math.Max(maxLen, right - left);
        }
        return maxLen;
    }
}
```

### TypeScript

```typescript
function longestSubarray(nums: number[]): number {
    let left = 0, zeroCount = 0, maxLen = 0;
    for (let right = 0; right < nums.length; right++) {
        if (nums[right] === 0) zeroCount++;
        while (zeroCount > 1) {
            if (nums[left] === 0) zeroCount--;
            left++;
        }
        maxLen = Math.max(maxLen, right - left); // 不是 right-left+1
    }
    return maxLen;
}
```

### Python

```python
def longestSubarray(nums: list[int]) -> int:
    left = zero_count = max_len = 0
    for right in range(len(nums)):
        if nums[right] == 0:
            zero_count += 1
        while zero_count > 1:
            if nums[left] == 0:
                zero_count -= 1
            left += 1
        # right - left 而非 right - left + 1
        max_len = max(max_len, right - left)
    return max_len
```

## 進階觀點

<Callout type="tip" title="面試追問">
- **為什麼是 right - left 而不是 right - left + 1？** 因為必須刪除一個元素，等於窗口長度少 1。
- **全是 1 的陣列怎麼辦？** 仍然必須刪除一個，所以答案是 n-1。我們的公式 right-left 在全 1 時，最大窗口為整個陣列，right-left = n-1，正好正確。
- **跟 Max Consecutive Ones III 的本質差異？** 翻轉是「不減少元素數量」，刪除是「減少一個」，所以答案差 1。
</Callout>
