# Non-overlapping Intervals

<ELI5>
你是一個活動場地管理員，有一堆活動要在同一個場地舉辦，但有些活動時間重疊了。你要取消最少的活動，讓剩下的活動都不衝突。

聰明的做法：優先保留「最早結束」的活動。因為結束得越早，後面的空間就越大，能排進更多活動。

這就像排行程：先做最快能完成的事，才有時間做更多事。
</ELI5>

## 題目描述

給定區間陣列 `intervals`，回傳需要移除的最少區間數量，使剩餘區間互不重疊。邊界相觸（如 [1,2] 和 [2,3]）不算重疊。

```
輸入：intervals = [[1,2],[2,3],[3,4],[1,3]]
輸出：1
解釋：移除 [1,3] 後，剩餘的 [1,2],[2,3],[3,4] 不重疊

輸入：intervals = [[1,2],[1,2],[1,2]]
輸出：2
```

## 解題思路

<StepDiagram data='[{"title":"按結束時間排序","description":"結束越早的區間排在前面","icon":"1"},{"title":"貪心選擇","description":"選第一個區間，記錄其結束時間","icon":"2"},{"title":"遍歷判斷","description":"下一個區間的開始 >= 上一個的結束 → 保留","icon":"3"},{"title":"重疊則跳過","description":"開始 < 上一個結束 → 需要移除，計數+1","icon":"4"},{"title":"統計移除數","description":"被跳過的區間數就是答案","icon":"5"}]' />

## 程式碼

### C#
```csharp
public class Solution {
    public int EraseOverlapIntervals(int[][] intervals) {
        // 按結束時間排序
        Array.Sort(intervals, (a, b) => a[1].CompareTo(b[1]));
        
        int removed = 0;
        int prevEnd = intervals[0][1];
        
        for (int i = 1; i < intervals.Length; i++) {
            if (intervals[i][0] < prevEnd) {
                removed++; // 重疊，移除當前區間
            } else {
                prevEnd = intervals[i][1]; // 不重疊，更新結束時間
            }
        }
        return removed;
    }
}
```

### Python
```python
def eraseOverlapIntervals(intervals: list[list[int]]) -> int:
    intervals.sort(key=lambda x: x[1])  # 按結束時間排序
    
    removed = 0
    prev_end = intervals[0][1]
    
    for start, end in intervals[1:]:
        if start < prev_end:
            removed += 1  # 重疊，移除
        else:
            prev_end = end  # 不重疊，保留
    
    return removed
```

## 進階觀點

<Callout type="tip" title="面試追問">
- 為什麼按結束時間排序而不是開始時間？按結束時間排序可以貪心地保留最多不重疊區間（Activity Selection Problem 的經典解法）。按開始時間排序需要額外處理「選哪個留下」的問題。
- 等價問題：最多能保留幾個不重疊區間？答案 = n - 移除數。
- **452. Minimum Number of Arrows** 是類似的區間貪心問題，差別在於邊界相觸也算重疊。
- 反過來按開始時間排序也能解，但遇到重疊時要保留結束時間較早的那個（需要更新 prevEnd 為 min）。
</Callout>
